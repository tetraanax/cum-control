# 참기 타이머

색 신호(초록·노랑·빨강)와 메트로놈 박자를 따라가며 정해진 시간 동안 버티는 브라우저 타이머입니다. 빌드 과정이 없는 정적 사이트입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. GitHub Pages에 올릴 때는 저장소 설정 → Pages → `main` 브랜치 루트를 선택하세요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 (설정 / 플레이 / 결과, 기록·사용법 모달, 성인 인증) |
| `style.css` | 디자인. 색상은 `:root` 변수에서 한 번에 바꿀 수 있습니다 |
| `app.js` | 타이머·메트로놈·큐 선택·확률·기록 로직 |
| `cues.js` | 지시문 목록. 여기만 고쳐도 내용을 바꿀 수 있습니다 |

## 작동 방식

- **난이도**: `app.js`의 `DIFF`에서 빨간 신호 비율, 템포 배율, 큐 지속시간 배율, 기본 허용 확률을 정합니다.
- **엔딩**: 추첨 / 무조건 허용 / 무조건 거부 / 아슬아슬(허용 3초).
- **배경 영상**: 갤러리에서 고른 영상을 신호 영역 뒤에 재생합니다(반복 재생·소리 선택). 영상은 기기에서만 재생되고 업로드되지 않습니다.
- **종료**: 플레이 중 버튼은 종료 하나뿐입니다(단축키 Esc).
- **저장**: 설정과 기록은 `localStorage`에만 저장됩니다. 설정 내보내기 파일에는 지시문 목록도 함께 들어갑니다.

## 수정 후 올릴 때

`index.html` 아래쪽의 `?v=7` 숫자(style.css, cues.js, voices/manifest.js, app.js 네 군데)를 하나씩 올려 주세요. 그래야 휴대폰 브라우저가 예전 파일을 캐시에서 쓰지 않고 새 파일을 받습니다.

## 루 목소리 (미리 녹음한 음성)

`voices/` 폴더에 지시문마다 mp3가 들어 있고, 설정 → 세부 설정 → 음성으로 읽기 → 목소리에서 고를 수 있습니다.

| 팩 | 엔진 | 비고 |
|---|---|---|
| InJoon, Hyunsu | Microsoft Edge 온라인 음성 (`msedge-tts`) | 가장 자연스러움. 공식 API가 아니라 무료 음성을 끌어다 쓰는 방식 |
| SNAP 애니체·친절체 | [SNAP Piper Korean](https://huggingface.co/softguy777/snap_piper_korean_22k) (Apache-2.0) | 오픈소스, PC에서 오프라인 생성 |

문장을 고치거나 레벨 4를 채운 뒤에는 음성을 다시 만들어야 합니다. 만들지 않은 문장은 기기 음성으로 읽습니다.

```
cd tools
npm install        # 처음 한 번
node make_voices.mjs
```

필요: Node, ffmpeg. 바뀐 문장만 새로 만들고, 안 쓰는 파일은 지웁니다. 목소리 팩 추가·삭제·속도는 `tools/make_voices.mjs` 위쪽 `PACKS`에서 바꿉니다.
